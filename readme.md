# vinheria-agnello-checkpoint03
Nome do projeto
vinheria-agnello-checkpoint03

Descrição
Sistema de controle de estoque da Vinheria Agnello. O projeto aplica objetos, arrays e funções de alta ordem, com todas as saídas exibidas via console.log e alert() 

- O que foi implementado
- Array de objetos com os vinhos da vinícola (nome, tipo, safra e estoque)
- adicionarVinho() – adiciona novos vinhos ao array
- listarVinhos() – lista todos os vinhos usando forEach
- filtrarEstoqueBaixo() – mostra os vinhos com estoque abaixo de 5 usando filter
- calcularEstoqueTotal() – calcula o estoque total usando reduce
- nomesEmCaixaAlta() – exibe os nomes dos vinhos em maiúsculas usando map
- Página index.html com título, descrição do sistema e estilização em CSS
- Saídas exibidas ao final
- Lista completa de vinhos
- Vinhos com estoque abaixo de 5
- Estoque total da vinícola
- Nomes dos vinhos em caixa alta
- Aluno(a)
